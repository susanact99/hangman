# Ahorcado / Adivina la palabra - React

Proyecto realizado con React + Vite.

## Instalar

Abre una terminal dentro de la carpeta del proyecto:

```bash
npm install
```

## Ejecutar

```bash
npm run dev
```

Después abre la dirección que muestra Vite, normalmente:

```text
http://localhost:5173
```

## Funcionamiento

- Se selecciona una palabra aleatoria.
- La palabra aparece oculta.
- Cada letra correcta se muestra.
- Las letras incorrectas se guardan.
- Hay 5 intentos.
- Cada fallo quita un corazón.
- No se puede introducir dos veces la misma letra.
- Cuando se completa la palabra, se gana.
- Cuando los intentos llegan a 0, se pierde.
- Se puede comenzar un nuevo juego.
